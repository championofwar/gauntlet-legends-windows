# Gauntlet Legends for Windows

An unofficial Windows runtime for the Nintendo 64 version of Gauntlet Legends, with widescreen support, selectable resolutions and controller remapping.

## What you need

A Windows PC and your own USA Nintendo 64 copy of Gauntlet Legends in `.z64` format. The Rom is not included in this download you will have to supply your own copy of the game

## How to play

1. Open Releases on this GitHub page and download the Windows playtest ZIP.
2. Right-click the ZIP and choose Extract All.
3. Open the extracted folder and double-click GauntletLauncher.exe.
4. Select your ROM when prompted. The launcher remembers it for next time.
5. Choose your graphics and controller settings, then start the game.

## Playtest feedback

If you run into a problem, open an issue on this GitHub page. Tell us where it happened and what you were doing. If the game crashes, attach Gauntlet-log.txt if available.
